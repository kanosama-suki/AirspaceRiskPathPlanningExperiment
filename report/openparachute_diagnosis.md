## 2. 反推 A_c,p 与 d_p

- `r_p = 0.3 m`，来源：`config.json` 的 `supplementary.R_P`。
- `r_a` 对应数据配置/公式中的 `r_u = R_U = 0.45 m`，来源：`config.json` 的 `supplementary.R_U`；半径和为 `0.75 m`。
- `h_p = 1.8 m`，来源：`config.json` 的 `supplementary.H_P`。
- 当前公式公共几何项 `π(r_p+r_u)^2 = 1.767145867644 m²`。
- 当前两阶段代码的 `A_c,p = 1.950598476916 m²`，`d_p_current = 0.122301739514 m`。
- A/B 前五探针由参考 R 反解的 `A_c,p` 范围：`1.930009797224–1.930010106740 m²`；均值 `1.930009920029 m²`。
- 用反解均值计算 `d_p_reference = 0.108576034923 m`。
- `d_p_current/d_p_reference = 1.126415600`；反向比 `d_p_reference/d_p_current = 0.887771796`。
- 面积比 `A_c,p_current/A_c,p_reference = 1.010667591`。

d_p 的比值不等于 R 的比值：A_c,p 公式还含有固定的圆形项 `π(r_p+r_u)^2`，而 R 的 M 组合还含 `(1−ETA)` 分支。反解时使用同一组 P_f、面积 A_c,b、P_LOC、人口密度和 ETA，10 个探针都回到约 `1.93001 m²`，因此现有证据支持差异集中在 d_p 对应的开伞面积项；没有看到需要另改 P_f 或几何常数项的证据。

## 3. 当前代码中的 d_p 速度口径

- 当前调用链：`verify_r.py` 将 `supplementary.T_1` 传入 `parachute_impact_components`；该函数返回开伞后水平速度及终端垂直速度；`compute_casualty_area_parachute` 按 `h_p × |v_h|/|v_v|` 计算 d_p。
- `v_h`：第二阶段在撞击时刻的瞬时水平速度。它由开伞瞬间的 `v_1^x(t_1)` 经式 (19) 衰减到落地时刻得到；不是渐近为零的终端水平速度，也不是两阶段平均速度。30 m 下当前值 `{horizontal_at_impact:.12f} m/s`。
- `v_v`：代码按 README 摘要简化，采用第二阶段垂直终端速度 `v_p^ter`，不是严格的撞击瞬时垂直速度。30 m 下 `{terminal_p:.12f} m/s`；按瞬时运动方程算得撞击值 `{vertical_at_impact:.12f} m/s`。
- `h_p = 1.8 m`，从 `supplementary.H_P` 读取。
- 代码中的式 (19) 水平速度：`v_2^x(τ) = 2 m v_1^x(t_1) / (ρ C_d,p S_p v_1^x(t_1) τ + 2m)`，其中 `τ = t − t_1` 是开伞后的经过时间；落地时取 `τ = parachute_time`。
- 论文式 (20) 的位移定义为 `x_d = ∫_0^{t_1} v_1^x(t)dt + ∫_{t_1}^{t_2} v_2^x(t)dt`、`y_d = ∫_0^{t_1} v_1^y(t)dt + ∫_{t_1}^{t_2} v_2^y(t)dt`。当前 helper 没有计算/使用完整 `x_d`；它积分第一阶段竖直位移并解第二阶段到地时间，之后用撞击速度比和 `h_p` 算 d_p。
- 用式 (20) 两阶段积分复算的诊断量：`x_1=13.765252817 m`、`x_2=7.850182029 m`、`x_d=21.615434846 m`、`y_d=30.000000000 m`；这些只用于候选比较，不是主代码输出。

## 4. 当前代码中的 t1 口径

- 当前代码把 `T_1` 当作从失效起点 `t=0` 到开伞的累计时间；因此它同时等于第一阶段时长。两种描述在本代码的时间原点下不是两个不同数值。
- 值来自 `config.json` 的 `supplementary.T_1 = 0.7`，没有硬编码；动力学公式使用 SI 单位，代码按秒解释。config/参数来源审计尚未为 `T_1` 明确标单位，故“秒”是当前模型解释而非 config 明文单位。
- `v_1^x(t_1)` 与 `v_1^y(t_1)` 均在开伞时刻取值；前者作为第二阶段初始水平速度，后者用于第二阶段垂直运动初值。没有用 t1 之后的阶段内时刻替代开伞状态。
- 第二阶段时长不是固定值：代码用第一阶段落差后剩余高度 `27.603693203 m`，解第二阶段垂直运动方程达到地面的时刻；本高度 `t_2−t_1=6.333249729 s`，总时间 `7.033249729 s`。

## 6. 结论

- **误差是否纯比例：**不是严格纯比例。窗口前 10 点重算/基准范围为 `1.004587217–1.009677195`；探针范围为 `1.004142849–1.009677178`。但按其他模型项反解出的 A_c,p 在 10 个探针间几乎恒定，支持一个共同的开伞面积偏差，而非多个独立偏差。
- **最可能偏差来源排序：**(1) `v_h` 的第二阶段撞击时刻/阶段时间定义；(2) `t_1` 的阶段含义及其到地积分口径（当前两种 t1 解释数值相同，尚不能区分）；(3) `v_v` 的终端速度简化与实际瞬时速度区别；(4) `h_p` 与 `r_p+r_u` 的配置值；(5) A_c,p 的圆形几何常数项。第 2 节的反推未显示第 (4)(5) 项本身有偏差。
- **最接近基准的候选：**候选 2，以及与它相同的候选 5a/5b；都得到约 `1.950598477 m²`，仍比反推基准高约 `1.0668%`，不能视为已修复。
- **仍需人工确认：**Drones 式 (19) 的时间变量究竟取从开伞开始的经过时间还是全局时刻；式 (20) 得到的两阶段位移是否被参考实现用于面积；`T_1` 的单位及其是否明确对应失效到开伞；基准 A_c,p 的确切速度/时刻约定。
