## M1 全局统计容差与 B 场景 summary 差异（2026-10-29）

- A/B 的 `slices/summary.json` 中 `r_median` 均为 log 直方图估值，并非精确排序中位数。summary 未保存 histogram 的桶边界和计数，因此无法复算基准的桶中心或桶内插值估值。
- A 的当前全量精确 `r_median` 与 summary 估值相差 `0.8887%`，在 README 的 `1%` 统计容差内；B 相差 `1.1447%`，超过 README 的 `1%` 容差。B 的 summary `r_median` / `r_norm` MISMATCH 继续保留，不写作计算通过。
- 主实验 `R_norm` 强制按当前全量 R 的精确有限值统计计算：`min(r_mean, r_median)`；不使用 `summary.json` 的直方图估值替代精确中位数，也不把 summary 估值写回风险计算。
- **基准精度限制接受：** B 的 `1.1447%` 差异按基准生成时 log 直方图估值的精度限制处理，当前作为已知差异接受，不认定为代码错误，也不阻断 M2。该归因依据 README 对估值方法的说明和 summary 缺少分桶数据；原分桶和估值算法不可复算，故此处是工程接受口径，不是独立复现证明。
- `verify_r.py --scope full --accept-known-diff` 仅在工程点位/结构校验通过、assumptions 保留本节接受记录，且唯一未通过项为 B 的 `r_median` / `r_norm` summary 差异时返回 0。summary 的严格 MISMATCH 状态仍留在 JSON 和日志；未传开关或出现其他失败仍返回 1。

## RiskA* 风险裁剪下界（2026-10-29）

- 用户给定 RiskA* 风险映射为 `clip(R / R_norm, eps, 1)`，但 `lib/03_场景/config.json` 和 RiskA* 原论文材料没有提供本工程 `eps` 的配置值。遵守 config 唯一参数源，不新增或改写场景参数；实现中暂用 `np.finfo(np.float64).eps`，并在 `src/algorithms/risk_astar.py` 作为明确的算法数值下界记录。
- A/B 本次全图最小 `R / R_norm` 分别约为 `0.05017` 和 `0.001605`，均远大于 float64 epsilon，因此该下界未改变本次 A/B 风险映射结果。若未来场景出现更小的正风险比，应先由论文/用户补充 `eps` 口径再用于正式实验。
- 影响：只影响低于 float64 可表示误差量级的正风险格；建筑和 NaN 格仍映射为 1，且由公共碰撞检查禁止通行。此项是公开实现假设，不声称为 Primatesta 原文参数。

## RC-A* 大包围盒中位数估值（2026-10-29）

- RC-A* 动态启发式的盒内均值始终用二维前缀和精确计算。盒内元素不超过 200,000 时，中位数用精确 `nanmedian`；更大的盒使用确定性三维等距抽样估计中位数，并按盒缓存。
- 依据：精确中位数版本在 A 场景 600 s 冒烟预算内只扩展 4,320 个状态并超时；启用确定性抽样后 A/B 任务 1 分别在约 18.75 s / 31.54 s 完成。
- 影响：大包围盒的 `R_med` 是启发式估值，不是严格精确统计量；可能影响节点展开顺序和搜索结果，但最终路径的碰撞、风险积分和综合代价仍由原始场景数据与公共评估器计算。日志中必须保留采用的估值方法。
- 后续若需要声称与论文精确启发式完全一致，应先实现并验证精确三维范围中位数查询，再重跑 A/B 冒烟和正式实验；当前结果只作算法可运行性冒烟，不用于排名。

## RRT* 半径参数映射（2026-10-29）

- 场景配置没有独立的 RRT* `eta` 半径键。实现以 `table2.STEP` 作为 `eta` 上限，符合本轮任务给出的“10 m 或更大”条件；不复用 `supplementary.ETA`，后者是降落伞成功率。
- `gamma` 按自由空间体积和三维单位球体积计算 Karaman-Frazzoli 理论阈值，并用 `math.nextafter` 向上取一个 binary64 间隔，满足 `gamma` 严格大于理论阈值的条件。冒烟记录会输出 `gamma` 和 `eta`。
- 本轮 60 s/seed 的 A 任务 1 冒烟中，seed 0 在预算内找到一条可行 incumbent，但规划状态仍为 `timeout`；seed 1、2 未找到可行路径。此结果只说明 seed 0 有可行路径，不代表该次运行收敛或渐近最优，不能用于性能排名。

## Informed RRT* 目标口径边界（2026-10-29）

- Informed 采样器按原版要求，以 `best_length`（目前已找到的最短可行几何路径长度）构造起终点焦点椭球；样本在连续世界坐标中生成，超出场景边界时拒绝并回退父类采样。
- 本轮约束要求复用 `RRTStarPlanner` 的树、选父和重连，因此继承的边代价仍由公共评估器计算综合代价。几何长度椭球与综合代价搜索目标并不完全一致，原版长度椭球不保证保留所有综合代价更优的长路径。
- 当前实现用于完成用户要求的原版长度椭球采样和可运行性冒烟；不能据此声称对公共综合代价渐近最优，也不用于算法排名。若正式比较要求综合代价目标一致，应单独设计并命名适配变体，例如 `Informed RRT*-C`，不得暗改原版。
- A 任务 1 三个 60 s seed 均为 `timeout`；seed 0 在 `13.2171 s` 找到 incumbent，seed 1/2 未找到可行路径。此小样本只报告可行性，不构成成功率或性能结论。
